# 后台求解器替换与代码说明

## 1. CP-SAT 是什么

CP-SAT 不是 Python 自带的功能，而是 Google OR-Tools 中专门求解约束规划、整数规划和部分混合整数规划的求解器。可以用它求解“每辆车执行哪个趟次、去哪个月台、什么时候开始装车、什么时候发车”这类离散调度问题。

Python 只负责运行代码；OR-Tools 需要单独安装。

## 2. 当前求解器结构

页面只向后台发送一个参数：

```json
{
  "scenario": "D3",
  "params": {
    "solver": "auto"
  }
}
```

后台所有求解器统一使用同一个入口：

```python
solve_scenario(scenario, data, params)
```

当前支持：

- `auto`：优先使用 CP-SAT，失败时回退启发式；
- `heuristic`：只使用启发式；
- `cpsat`：只使用 CP-SAT，失败时明确报错。

这样切换求解器时，页面、CSV数据和服务器接口都不需要重写。

## 3. 代码怎么编写

CP-SAT 建模可以按以下顺序写：

1. 读取 trips、vehicles、docks、prep、charging 五类数据；
2. 建立 `assign[b,h]`，表示趟次 `b` 是否分配给车辆 `h`；
3. 建立 `use_dock[b,d]`，表示趟次 `b` 是否使用月台 `d`；
4. 建立准备开始、准备结束、装车开始、装车结束、发车和返场时间变量；
5. 写出容量、可用时间、充电完成、月台不冲突、车辆不冲突等约束；
6. 写出成本、等待和延误的目标函数；
7. 调用 `CpSolver().Solve(model)`；
8. 把求解结果转换成页面需要的 `schedule` 和 `kpi`。

本项目对应文件：

- `simulation/scenarios.py`：情景 ID、默认等待上限、里程折算系数、等待口径等常量；
- `simulation/scheduler.py`：求解器总入口；
- `simulation/scheduler.py::_solve_heuristic`：启发式代码；
- `simulation/cpsat_scheduler.py::solve_with_cpsat`：CP-SAT代码。

> **口径一致性提醒**
> 两个求解器必须使用同一套情景口径，否则“五情景效益对比”会自相矛盾。
> 具体包括：H0 的里程折算系数 1.22、等待口径按 30 分钟截断（`wait_floor_min`）、
> C3/D3 中长线 R2/R4 保留燃油车。相关常量统一放在 `simulation/scenarios.py`，
> 改动时请同时检查两个求解器。
>
> 即便口径对齐，两者结果仍会不同：CP-SAT 会在可用车队中自由选择最省钱的车辆，
> 而启发式按第三章“现状车队 → 新能源替换”的口径排班。因此部署时
> `PLATFORM_DEFAULT_SOLVER` 默认使用 `heuristic`，保证与汇报材料一致，
> 详见 `docs/部署到Ubuntu宝塔面板.md` 第 7 节。

## 4. 如何换到另一个求解器

以 ALNS 为例：

第一步，新建：

```text
simulation/alns_scheduler.py
```

第二步，实现同样接口：

```python
def solve_with_alns(scenario, data, params):
    return {
        'scenario': scenario,
        'solver': 'alns',
        'schedule': [],
        'kpi': {},
        'notes': []
    }
```

第三步，在 `scheduler.py` 中增加分支：

```python
if solver_type == 'alns':
    from simulation.alns_scheduler import solve_with_alns
    return solve_with_alns(scenario, data, params)
```

第四步，在页面下拉框中增加 `ALNS` 选项。

只要返回格式不变，前端表格、甘特图和KPI卡片不用改。

## 5. 代码附件怎么提交

竞赛代码附件建议同时提交：

- 完整平台源码压缩包；
- `README.md`运行说明；
- `requirements.txt`依赖清单；
- `data/demo`演示数据；
- 如果评委会检查求解过程，再附一份 `CP-SAT建模说明.md`。

不建议只交一个Python文件，也不建议把本机的虚拟环境、缓存和密钥一起打包。
